# Инженерный калькулятор компонентов DC-DC регулятора MPQ8626GD (IS6605A)

Профессиональный инженерный калькулятор для расчета всех пассивных и силовых компонентов синхронного понижающего регулятора **Monolithic Power Systems (MPS) MPQ8626GD** и его функционального аналога **Innovision Semiconductor IS6605A** (входное напряжение 4.0В – 16.0В или 2.85В – 16В с внешним смещением 3.3В, ток нагрузки до 6А, корпус QFN-14 2×3 мм).

---

## Возможности калькулятора

- **Поддержка чипов:** MPS MPQ8626GD и Innovision Semiconductor IS6605A.
- **Расчет силовой ступени:** индуктивность L1 (Kind 0.20..0.50), эффективная емкость COUT (по пульсациям, динамическому сбросу нагрузки и критерию устойчивости COT), входная батарея CIN с учетом действующего тока Irms и DC-bias дерайтинга.
- **Интерактивная схема QFN-14:** векторная интерактивная схема всех 14 выводов (VIN, SW, CS, EN, FB, AGND, TRK/REF, PGOOD, BST, MODE, VCC, PGND) с подсказками по разводке и формулами из даташитов.
- **Конфигурация MODE (Пин 12):** выбор режимов Forced CCM (FCCM) и Pulse Skip (PSM) на частотах 600 кГц, 1100 кГц (1.1 МГц) и 2000 кГц (2.0 МГц) по номиналам резисторов (0 Ом AGND, 30.1к, 60.4к, 121к, 243к, шина VCC).
- **Токовый предел CS (Пин 4):** расчет сопротивления R_CS по формуле отсечки впадины тока Ivalley и сопоставление с калибровочной таблицей даташита MPS.
- **Плавный пуск TRK/REF (Пин 8):** расчет внешнего конденсатора C_REF для времени софт-старта Tss > 2.2 мс (MPQ8626) или > 1.4 мс (IS6605A).
- **Защита UVLO / EN (Пин 5):** расчет делителя Rup / Rdown с контролем порога включения и проверкой предельного напряжения на выводе EN (макс. 3.6 В).
- **Feed-Forward Cff (Пин 6):** расчет конденсатора опережения по фазе для оптимального нуля fz в диапазоне 5..40 кГц.
- **Спецификация BOM:** экспорт перечня компонентов в CSV/Excel с посадочными местами и рейтингами.
- **Экспорт в JSON и Python:** мгновенная генерация автономного скрипта `mpq8626_calculator.py` на чистом Python 3.

---

## Варианты запуска

### Вариант 1. Веб-интерфейс (React + Vite + Tailwind CSS)
```bash
npm install
npm run dev
```
Открыть в браузере `http://localhost:3000`.

### Вариант 2. Автономный консольный Python-скрипт
```bash
python mpq8626_calculator.py
python mpq8626_calculator.py sample_preset_12v_1v8_6a.json
```
